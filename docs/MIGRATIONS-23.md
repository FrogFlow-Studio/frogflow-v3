# Миграции партии 23

Миграции партии не трогают таблицы, колонки и данные: только индексы и настройки функций. Каждая лежит в `migrations/23-*.sql`, к каждой есть пара `.down.sql`. **В базу их применяет только Яков, своим словом.** Код работает и без них, только медленнее.

| №    | Файл                   | Что меняется                                                                                                                                                                                                                                                                                | Откат                                                                  |
| ---- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 23-1 | `23-1-indexes-advisor` | Добавлен индекс `zernio_logs (bot_id, event_id text_pattern_ops)` для поиска по началу `event_id` (обращения, outbox, розыгрыши). Снят дубль уникального индекса `bot_users (bot_id, telegram_id)`. У `reset_orders_sequence` и `platform_threads_seller_status` зафиксирован `search_path` | `.down.sql` удаляет индекс, возвращает дубль, сбрасывает `search_path` |
| 23-2 | `23-2-fk-indexes`      | Добавлены индексы на 18 внешних ключей без индекса (советник `unindexed_foreign_keys`): `order_items`, `cart_items`, `orders.delivery_zone_id`, `vip_subscriptions`, `vip_member_profiles` и др.                                                                                            | `.down.sql` удаляет эти 18 индексов                                    |

Индексы строятся обычным `CREATE INDEX`. Журнал в 23-1 небольшой (46 тыс. строк на 08.10.2026), таблицы в 23-2 ещё меньше (до 2 тыс. строк), поэтому блокировка записи длится доли секунды.
