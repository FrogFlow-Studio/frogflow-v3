# Миграции партии 23

Миграция не трогает таблицы, колонки и данные. Она добавляет индекс, снимает дубль индекса и задаёт настройки функций. Лежит в `migrations/23-1-indexes-advisor.sql`, к ней есть пара `.down.sql`. **В базу её применяет только Яков, своим словом.** Код работает и без неё, только медленнее на поиске по журналу.

| №    | Файл                   | Что меняется                                                                                                                                                                                                                                                                                | Откат                                                                  |
| ---- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 23-1 | `23-1-indexes-advisor` | Добавлен индекс `zernio_logs (bot_id, event_id text_pattern_ops)` для поиска по началу `event_id` (обращения, outbox, розыгрыши). Снят дубль уникального индекса `bot_users (bot_id, telegram_id)`. У `reset_orders_sequence` и `platform_threads_seller_status` зафиксирован `search_path` | `.down.sql` удаляет индекс, возвращает дубль, сбрасывает `search_path` |

Индекс строится обычным `CREATE INDEX`. Журнал небольшой (46 тыс. строк на 08.10.2026), поэтому блокировка записи длится доли секунды.
