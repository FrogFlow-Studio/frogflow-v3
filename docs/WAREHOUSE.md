# Склад и закупки (партия 18, дорожка С)

Модуль `warehouse` (требует `stock`; в тарифах Pro и Business для кондитерских и цветочных).
Схема базы не менялась: всё лежит в `app_settings` и в журнале событий `zernio_logs`.

| Часть          | Где хранится                                                                      | Код                           |
| -------------- | --------------------------------------------------------------------------------- | ----------------------------- |
| Поставщики     | `app_settings` `suppliers` (`{rev, items}`), привязка товара — `supplier_of:<id>` | `src/core/stock/suppliers.ts` |
| Приходы        | `stock:receipt:<id>`, счётчик `stock:receipt_seq`; событие `stock.receipt`        | `src/core/stock/receipts.ts`  |
| Списания       | событие `stock.writeoff` (причина, комментарий, себестоимость единицы)            | `src/core/stock/writeoff.ts`  |
| Инвентаризация | `stock:stocktake` (одна открытая сессия); событие `stock.stocktake`               | `src/core/stock/stocktake.ts` |
| Журнал склада  | чтение событий `stock.*`, CSV `/api/admin/export/stock-journal`                   | `src/core/stock/journal.ts`   |

## Правила

- Остаток меняется условной записью «остаток всё ещё такой, как прочитали» с повтором, и только
  на разницу, а не «записать посчитанное»: параллельные заказы не теряются.
- Приход и инвентаризация сначала занимают документ условной записью (`posting`), строки применяет
  только выигравший; зависший `posting` старше 150 с можно подхватить и довести до конца.
- Себестоимость при приходе — средневзвешенная. У вариантов собственного остатка нет: остаток общий
  на товар, вариант хранит только свою себестоимость.
- Списания попадают в «Прибыль» отдельной строкой «Списания склада» (только при включённом модуле).
- Хранение: события `stock.receipt`, `stock.writeoff`, `stock.stocktake` — бухгалтерские и не
  удаляются чисткой журналов; остальные движения хранятся 180 дней.
- Журнал склада и CSV открыты бухгалтеру (`journalFn`, `journalProductsFn`); остальные функции
  склада — владельцу и менеджеру. Фильтр «Поставщик» отбирает приходы этого поставщика.
- Лист ожидания приходом не запускается (отдельный шаг, пока не сделан).
