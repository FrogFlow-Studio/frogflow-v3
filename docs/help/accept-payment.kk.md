# Төлемді қалай қабылдауға болады

keywords: төлем, реквизиттер, qr, чек, kaspi, каспи, аударым, ақша, қалай төлеу, сатып алушы төлейді
group: start
order: 4

Сатып алушы тапсырысты сіздің реквизиттеріңіз бойынша төлеп, чек жібереді. Төлемді өзіңіз растайсыз немесе бот чекті автоматты түрде тексереді.

1. [Төлем және баптаулар](/admin/settings) бетін ашып, «Реквизиттер мен нұсқаулық» бөлімін таңдаңыз.
2. Төлем тәсілін қосыңыз: сатып алушының елі үшін реквизиттер және, бар болса, QR-код. Тізімдегі бірінші ел негізгі болып саналады: сатып алушының елі белгісіз болса, баға сол бойынша есептеледі.
3. Төлем тәсілін қосыңыз («Белсенді»). Сатып алушы реквизиттерді тапсырыс рәсімдеу кезінде көреді.
4. Чек келгенде «Жаңа тапсырыс және чек» хабарламасын аласыз: соманы тексеріп, [тапсырыс](/admin/orders) карточкасында төлемді растаңыз.

Чектерді автоматты оқу қосылған болса (ақылы опция, баптаулар карточкасында тариф көрсетілген), сәйкес келген чек сіздің қатысуыңызды қажет етпейді, ал күмәнді чек себебімен бірге сізге келеді. Карталық тәсілдер (мысалы, Robokassa) сол баптауларда бапталып, бөлек қосылады.
