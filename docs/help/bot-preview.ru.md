Страница показывает, как ваш бот выглядит для покупателя в Telegram при текущих настройках и модулях. Ничего никому не отправляется, заказы не создаются. Где найти: «Меню → Настройки → Предпросмотр бота». Доступна всем, кроме бухгалтера.

## Что показано {#feed}

Лента идёт по шагам покупателя:

- «Покупатель выбирает язык» — выбор языка, если магазин работает на нескольких языках.
- «Покупатель нажимает «Старт»» — приветствие. Его текст меняется на странице [Тексты бота](/admin/bot-texts).
- «Покупатель открывает товар» — карточка товара с кнопками. Цена показана для страны по умолчанию, с действующей акцией.
- «Кнопки внизу экрана» — меню бота.

Если в каталоге нет активных товаров, карточки товара не будет: сначала добавьте товар.

## Язык покупателя {#language}

Если в магазине несколько языков, в «Язык покупателя» выберите, на каком языке смотреть бота. Лента перерисуется на этом языке.

## Товар для карточки {#product}

По умолчанию показывается один из ваших товаров. Чтобы посмотреть другой:

1. Впишите часть названия в «Найти товар по названию».
2. Нажмите кнопку поиска.
3. Выберите товар в списке.

## Если у вас ИИ-консультант без продаж {#consultant}

Консультант отвечает по-своему, поэтому вместо ленты будет кнопка «Открыть тест-чат консультанта»: там можно задать вопрос и увидеть ответ.
