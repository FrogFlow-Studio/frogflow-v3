# The buyer did not get the "Buy" button or the message in Direct

keywords: button did not arrive, no button, message did not arrive, direct, dm, comment without reply, rule not working, not replying to comment, where is the link, nothing came, knopka
group: trouble
order: 10

First work out what exactly did not arrive: the first message after the comment, or the "Buy" button that comes as the second message.

1. Open [Instagram](/admin/instagram) and find the rule for this post. It should show "active". A switched-off rule sends nothing, including the promised buttons.
2. Check the keywords: the comment must contain them (or "Reply to any comment" is on).
3. Press "Trigger history" and set "only failed": it shows who did not get the message and why.
4. If the first message went out but there is no button, the buyer has not replied to it yet. The "Buy" button comes after any reply from the buyer in Direct, within 24 hours.
5. If the rule stayed silent, open "Catch-up sending by comments" on the same page, choose the post, press "Load comments" and send the message to those who did not get it.

## The buyer does not see the message {#requests}

Instagram puts messages from accounts the person does not follow into the "Requests" folder, not into the main inbox. If the person posts another comment like "nothing came", the bot replies under it by itself that the message is in "Requests" and they need to reply "+".

## The button was sent, but for the wrong product {#wrong}

Check that the rule has exactly this post's product. When you save a rule with a product that is not in the post caption, the panel warns you about it.

## Lots of comments under a post, but no orders {#no-button}

That means the rule for this post has no "Buy" button. Open the rule, press "+ Product" and choose the post's product. Without the button the buyer gets only text and then writes to you by hand.

## What cannot be fixed {#limits}

Instagram allows one private message per comment and no later than a week after it. Replies in a thread under someone else's reply and old conversations are sometimes blocked by Instagram: see [Instagram blocks a message to an old conversation](/admin/help?a=old-conversation).
