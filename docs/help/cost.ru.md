# Себестоимость товаров

keywords: себестоимость, закупочная цена, затраты, прибыль, маржа, наценка, валовая прибыль, бухгалтер

group: guide

order: 320

pages: /admin/cost

Сколько вам обходится каждый товар. Из этого в [Аналитике](/admin/analytics) и отчётах считается валовая прибыль. Где найти: «Меню → Аналитика → Себестоимость». Раздел есть, если подключён учёт прибыли. Править может менеджер и выше, а также бухгалтер; сотрудник «только просмотр» — нет.

## Себестоимость товара {#cost}

Поле «Себестоимость» в валюте товара и «Сохранить». Пусто — «не задана», а не ноль: такой товар в прибыль не входит. Ноль вводите, только если затрат на товар правда нет.

## По вариантам {#variants}

У товара с вариантами можно задать себестоимость каждого варианта. Вариант без своей суммы берёт себестоимость товара («как у товара»).

## Только без себестоимости {#only-missing}

Галочка оставляет товары, у которых себестоимость не задана. Сверху — «Без себестоимости: … из …». Если у товаров себестоимость записана в другой валюте, чем цена, панель попросит ввести её заново.

Себестоимость меняется и при проведении прихода на [складе](/admin/warehouse), если там включён пересчёт.
