# Two orders with the same number

keywords: same number, duplicate order, two orders, number repeats, repeated number, order doubled, double order, dubl
group: trouble
order: 80

There are two different cases: two different buyers ended up with the same order number, or one buyer placed two orders in a row.

## One number for different buyers {#same-number}

In rare cases order numbers repeated after nightly database maintenance. The order itself is not affected: each has its own buyer, items and receipt.

1. In [Orders](/admin/orders) find the number with the search: both orders will show up.
2. Tell them apart by the buyer's name, the date and the amount.
3. Confirm the one the receipt came for: the receipt is visible in the order card under "Payment receipt".
4. If the buyer gives only the number, ask for their Instagram name or the amount.

If you see a repeated number, write the number and the date to [Support](/admin/support): we will check it.

## The buyer placed two orders {#double}

Usually it is a double tap on "Buy" or a repeated order after a question. Keep the one the receipt came for, and open the extra one and choose "Reject" in the "More" menu. The buyer will get a rejection notification, so briefly warn them in "Inbox" that the second order was extra.
