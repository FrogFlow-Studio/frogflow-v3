# Instagram-ды қалай қосуға болады

keywords: инстаграм, инста, директ, direct, аккаунтты қосу, whatsapp, ватсап, мессенджер, авторизация, қайта қосу
group: start
order: 2

Бот Direct-те сатып алушыларға жауап береді, каталог пен тапсырыстарды жүргізеді, күрделі сұрақтарды «Чат» арқылы сізге береді.

1. [Төлем және баптаулар](/admin/settings) бетін ашып, «Instagram және WhatsApp» блогын табыңыз.
2. «Instagram қосу» батырмасын басыңыз (WhatsApp үшін — «WhatsApp қосу»), аккаунтқа кіріп, сұралған рұқсаттарды беріңіз.
3. Баптауларға оралып, «Жаңарту» батырмасын басыңыз: блокта «Қосылған аккаунттар: 1» және «жұмыс істеп тұр» күйі шығуы керек.

«Қайта қосу керек» деп жазылса, авторизация мерзімі өткен: аккаунтты қайтадан қосыңыз. Қосу батырмалары жоқ болса, платформада мессенджерлерді қосу әлі бапталмаған — бізге [Қолдау](/admin/support) арқылы жазыңыз.

Посттардағы пікірлерге автожауаптар бөлек, [Instagram](/admin/instagram) бетінде бапталады.
