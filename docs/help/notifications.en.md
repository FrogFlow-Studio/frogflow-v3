# Notifications in the admin panel

group: guide
order: 85
pages: /admin/notifications

The feed of shop events for the last 30 days: new orders, receipts to review, refunds and reviews. Where to find it: "Menu → Sales → Notifications". Seen by everyone who has orders, including the accountant.

This is a feed inside the admin panel. Where else notifications go (Telegram, email, quiet hours) is set in the "Notifications" section on the [Payment and settings](/admin/settings) page: see the article [Settings: bots and notifications](/admin/help?a=settings-bots) for details.

## Feed {#feed}

Events are grouped: "Today" and "Earlier". New ones are marked "New". Each row leads to the order:

- "New order #…"
- "Receipt to review: order #…": open the order and check the receipt;
- "Refund on order #…"
- "New review: … of 5"

If there are many events, the bottom says how many of the latest are shown out of the total.

## Filters {#filters}

The "All", "Orders", "Receipts", "Reviews", "Refunds" buttons keep events of one kind. Only the buttons that have events are shown.

## Mark all as read {#mark-read}

"Mark all as read" removes the "New" mark from all events. The button is there while there are unread events.
