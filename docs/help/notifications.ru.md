Лента событий магазина за последние 30 дней: новые заказы, чеки на проверке, возвраты и отзывы. Где найти: «Меню → Продажи → Уведомления». Видят все, у кого есть заказы, в том числе бухгалтер.

Это лента внутри админки. Куда ещё приходят уведомления (Telegram, почта, тихие часы), настраивается в разделе «Уведомления» на странице [Оплата и настройки](/admin/settings) — подробно в статье [Настройки: боты и уведомления](/admin/help?a=settings-bots).

## Лента {#feed}

События сгруппированы: «Сегодня» и «Раньше». Новые помечены «Новое». Каждая строка ведёт в заказ:

- «Новый заказ №…»
- «Чек на проверке: заказ №…» — откройте заказ и проверьте чек;
- «Возврат по заказу №…»
- «Новый отзыв: … из 5»

Если событий много, внизу написано, сколько последних показано из общего числа.

## Фильтры {#filters}

Кнопки «Все», «Заказы», «Чеки», «Отзывы», «Возвраты» оставляют события одного вида. Показываются только те кнопки, для которых есть события.

## Отметить всё прочитанным {#mark-read}

«Отметить всё прочитанным» снимает пометку «Новое» со всех событий. Кнопка есть, пока есть непрочитанные.
