# Reports center

keywords: reports, report, sales, profit, warehouse, points, broadcasts, refusals, csv, print, period comparison, accountant, otchety

group: guide

order: 310

pages: /admin/reports

Sales, profit, warehouse, points, broadcasts and refusals in one place: a period, a comparison with the past, CSV and printing. Where to find it: "Menu → Analytics → Reports". The section exists if analytics is connected; the accountant sees it too.

## Report type {#kinds}

The "Sales", "Profit", "Stock", "Points", "Broadcasts", "Refusals" tabs. The table: "Metric", "Period", "Previous period", "Change, %".

Sales and profit are counted the same way as in [Analytics](/admin/analytics): only paid orders go into revenue. Points are only shown, not recalculated.

## Period {#period}

Buttons with a number of days choose the period; the comparison is with the same period before.

## Download and print {#export}

"Download CSV" — the current report as a table for Excel. "Print" — a version for printing or saving as PDF.
