# Consultant tasks

Buyers the AI consultant handed over to you: they want to buy, ask about wholesale, complain, ask for a human or a photo, or asked a question the consultant has no answer to. Where to find it: "Menu → Consultant → Tasks" (in the consultant workspace, for managers and above). The number next to the menu item is how many tasks are open.

## How a task closes {#closing}

A task closes by itself when you reply to the buyer: in the panel "Dialogues", right in Instagram or WhatsApp, or by replying to the task card in Telegram. Under a closed task you can see how it was closed: "Closed by you", "you replied in “Dialogues”", "to the card in Telegram", "in Instagram", "in WhatsApp".

Handoff reasons: "Ready to buy", "Wholesale", "Complaint or return", "Asks for a human", "Asks for a photo or video", "Unanswered question", "Handed to a manager".

Telegram reminders about unhandled tasks are turned on in the [Consultant price list](/admin/help?a=pricelist), with the "Remind me about open tasks in Telegram" checkbox.

## Open and done, channel {#filter}

The "Open" and "Done" tabs with the number of tasks. "Channel" keeps only tasks from Telegram, Instagram or WhatsApp ("All channels" — all of them).

## Task actions {#actions}

- "Open dialogue" — the conversation in the panel "Dialogues" (if the manager chat module is on). Otherwise — "Open in Instagram" (or in another channel), and the conversation opens there.
- "Done" — close the task manually, for example if you answered by phone.
- "Back to work" — reopen a done task.

## Clearing the list {#cleanup}

- "Remove done" — remove all done tasks from the list.
- "Delete all" — delete all tasks, including open ones. This can't be undone.

The list keeps the last 200 tasks: when it overflows, old done tasks are removed; open tasks are never removed.
